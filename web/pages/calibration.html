Checking

Calibrate from File… imports a calibration scan (for example a saved crop) and fits all of it. The file decides the calibration: with yaw, pitch and roll columns it uses the IMU method (offset, scale, soft iron, misalignment to the IMU and the Earth field); without them, the ellipsoid method (|B| is calibrated; components keep the sensor's misalignment). Fit Cropped Window fits the open scan's window and selected channels instead, with the method below.

Apply Calibration

Corrects every row of the open scan with C (Braw − b) and writes the sample axis plus B east/north/up and |B| in nT. Uses the scan's yaw/pitch/roll when present, otherwise assumes a level, north-facing sensor. The output opens in Offline Data.

Calibration: none yet. Fit one, or open a calibration JSON.

Files are read by this browser and sent to the dashboard server for parsing; nothing is stored on the server. B units come from the column names (T, µT, nT, gauss; none means nT). Yaw/pitch/roll are aerospace Z-Y-X angles of the IMU body (forward/right/down); rad or deg in the name sets the unit, otherwise values beyond ±2π are read as degrees. Rows with a missing value are skipped by the fit.
